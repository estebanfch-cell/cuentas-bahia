Cuentas Bahía

Para que toda la familia vea lo mismo en tiempo real, hay que conectar la app a una base de datos gratuita (Firebase de Google). Se hace una sola vez, toma ~10 minutos y no necesita tarjeta.

1
Entra a console.firebase.google.com con una cuenta de Google y pulsa “Crear un proyecto”.
2
Realtime Database → Crear base de datos, modo de prueba. En la pestaña Reglas publica:
{ "rules": { ".read": true, ".write": true } }
3
Configuración del proyecto → Tus apps → </> → registra la app y copia el bloque firebaseConfig.
4
Pega la configuración en este archivo donde dice PEGA AQUÍ, o pídele a Claude que lo haga.
5
Publica el archivo (GitHub Pages o Netlify) y comparte el link con la familia.

En modo demo los datos se guardan solo en este navegador.

Cuentas Bahía

Para que toda la familia vea lo mismo en tiempo real, hay que conectar la app a una base de datos gratuita (Firebase de Google). Se hace una sola vez, toma ~10 minutos y no necesita tarjeta.

1
Entra a console.firebase.google.com con una cuenta de Google y pulsa “Crear un proyecto” (ponle un nombre como cuentas-bahia; puedes desactivar Google Analytics).
2
En el menú izquierdo: Compilación → Realtime Database → Crear base de datos. Elige la ubicación por defecto y el modo de prueba. Luego, en la pestaña Reglas, deja las reglas así y publica:
{ "rules": { ".read": true, ".write": true } }
(cualquiera con el link puede escribir — perfecto para uso familiar)
3
Ve a Configuración del proyecto (engranaje) → sección Tus apps → pulsa el ícono </> (web) → regístrala con cualquier nombre → copia el bloque firebaseConfig que te muestra.
4
Abre este archivo (index.html) con un editor de texto, busca PEGA AQUÍ cerca del inicio del código y pega tu configuración. O más fácil: pégale ese bloque a Claude y te devuelve el archivo ya listo.
5
Publica el archivo para tener tu link: entra a app.netlify.com/drop (cuenta gratis), arrastra el archivo y te da un link tipo cuentas-bahia.netlify.app. Ese link es el que compartes con la familia.

En modo demo los datos se guardan solo en este navegador.
